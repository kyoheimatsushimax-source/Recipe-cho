# レシピ帖

Claudeにもらったレシピを保存し、お気に入り度（★1〜5）と「作った記録」でレパートリーを育てるPWAです。

## ファイル構成（すべて同じ階層・サブフォルダなし）

```
index.html              アプリ本体
manifest.json           PWA設定
sw.js                   オフライン対応
icon-192.png            アイコン
icon-512.png            アイコン
icon-maskable-512.png   アイコン（Android用）
apple-touch-icon.png    アイコン（iPhoneホーム画面用）
README.md               この説明
```

アイコンはあえて `icons/` フォルダに入れず、同じ階層に置いています。
GitHubの画面からアップロードするとき、7ファイルをまとめてドラッグするだけで済み、フォルダ階層が崩れてアイコンが出ない問題が起きません。

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作る（例：`recipe`）。Public。
2. 「uploading an existing file」から、ZIPを解凍した中身のファイル全部を選んでアップロード → Commit。
3. Settings → Pages → Branch を `main` / `(root)` にして Save。
4. 1〜2分後、`https://（アカウント名）.github.io/recipe/` をiPhoneのSafariで開く。
5. 共有ボタン → 「ホーム画面に追加」。

## 使い方

### Claudeのレシピを保存する
1. Claudeにレシピを頼む。回答の最後に「取込コード」が付く。
2. コードブロック右上のコピーボタンを押す。
3. レシピ帖 → 「追加」→「クリップボードから取り込む」。

取込コードが付かなかったときは、「追加 → Claudeに頼む」で依頼文をコピーして送ると確実です。

### 育てる
- 詳細画面の★でお気に入り度を登録（同じ★をもう一度押すと解除）。
- 「作った！」で日付を記録。回数と最終日が一覧に出ます。
- 人数の＋−で材料の分量を自動換算。
- 自分メモに次回への改善点を残す。
- 「きょうの一品」でお気に入り／ごぶさた／未挑戦から1品提案。
- 「記録」でレパートリー数・目標の進み具合・ジャンルの偏りを確認。

## 取込コードの形式

```json
{"app":"recipe-cho","v":1,"recipes":[{
  "title":"料理名","desc":"ひとこと説明",
  "genre":"和食|洋食|中華|エスニック|その他",
  "category":"主菜|副菜|汁物|ごはん・麺|おやつ|その他",
  "servings":2,"time":20,
  "ingredients":[{"name":"鶏もも肉","amount":300,"unit":"g"},{"name":"しょうゆ","amount":2,"unit":"大さじ"},{"name":"塩","amount":"少々","unit":""}],
  "steps":["手順1","手順2"],"tips":"コツ","tags":["時短"]
}]}
```

- `amount` は数値（人数換算の対象）。計れないものは `"少々"` などの文字。
- `time` は分。`recipes` に複数入れれば一度に取り込めます。

## データについて

- データはこの端末のブラウザ内（localStorage）だけに保存され、外部には送信されません。
- Safariで開いた場合とホーム画面アイコンから開いた場合は保存場所が別です。必ずホーム画面のアイコンから使ってください。
- 機種変更やアイコン削除でデータは消えます。「記録 → バックアップ」でときどき書き出してください。復元は「追加 → Claudeから取込」に貼り付けるだけです。

## 更新するとき

ファイルを差し替えたら、`sw.js` の `CACHE` の番号（v1 → v2）を上げてください。
